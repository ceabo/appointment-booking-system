# Appointment Booking System

A simple appointment booking system built with Python, Flask, SQLite and Bootstrap.

## Features

* Create appointments
* View appointments
* Update appointments
* Delete appointments
* Search by name or mobile number
* Flash messages
* Responsive Bootstrap UI

## Technologies
* Python
* Flask
* SQLite
* Bootstrap 5

## Installation
```bash
pip install flask
python app.py
```

## Project Structure
```text
appointment_project/
├── app.py
├── database.py
├── appointments.db
└── templates/
```
